# Quote Generator | Random Quote App with Lottie Animation

A simple, responsive, and visually attractive **Quote Generator** built with **HTML, CSS, and JavaScript**.  
This project fetches a random quote from an API and displays it in a clean UI with smooth **Lottie animations**, gradient text, and a modern card layout.

## Overview

The **Quote Generator** is a beginner-friendly web project that shows how to work with:

- HTML structure
- Modern CSS styling
- Flexbox centering
- Gradient text effects
- Lottie animations
- JavaScript `fetch()` API
- Async/await
- DOM manipulation
- Error handling with `try...catch`

It is designed to be lightweight, responsive, and easy to understand.

## Features

- Random quote generation with one click
- Beautiful gradient heading and text
- Lottie animation support
- Responsive design for mobile and desktop
- Modern card-style UI
- Loading state while fetching data
- Error message handling if the API fails
- Beginner-friendly JavaScript API integration

## How It Works

1. The user clicks the **Get a Quote** button.
2. JavaScript sends a request to the quote API.
3. The response is converted into a JavaScript object.
4. A random quote is selected and displayed on the page.
5. If the request fails, an error message is shown.

## API Used

This project uses the following API:

`https://dummyjson.com/quotes/random`

It returns quote data in JSON format.
